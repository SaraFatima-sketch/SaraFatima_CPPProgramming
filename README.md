# Student Record Management System 🎓

A console-based **Student Record Management System** implemented in **C++** using Object-Oriented Programming (OOP) concepts and Standard Template Library (`std::vector`).

## 📌 Project Features
- **Add Student Record:** Add student details including Roll Number, Name, and Marks.
- **Display Records:** View all stored student records in a clean tabular layout.
- **Update Record:** Modify existing student records using their unique Roll Number.
- **Console Interface:** Simple, interactive menu for easy navigation.

## 🛠 Tech Stack
- **Language:** C++
- **IDE / Editor:** Visual Studio Code
- **Compiler:** MinGW / GCC
